## Project: Greeting Program
This program asks the user for their name and displays a personalized greeting.

## Features
- Takes the user's name as input.
- Prints a personalized greeting.
- Displays a welcome message.

## Requirements

## How to Run
1. Open `main.py`.
2. Run it using Python.
3. Enter your name when prompted.

Welcome to my AI learning journey.
